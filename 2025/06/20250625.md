# 이펙티브 코틀린(ch2)

### 리시버를 명시적으로 참조하라
- also, let을 활용해 명시적으로 리시버 참조 - nullable값 처리에 적합
- 둘 이상의 리시버: 레이블(@)활용해서 명시적으로 지정
- @DslMarker: DSL 선언/코드 작성시 실수로 바깥 리시버의 메서드를 호출X

#### 리시버
- 리시버: 객체 외부의 람다 코드 블록을 마치 해당 객체 내부에서 사용하는 것 처럼 작성할 수 있게 해주는 장치
~~~ kotlin
class Person(val name: String) {
    fun printInfo() {
        println("Hello, I'm $name") // 여기서 name은 this.name
    }
}
~~~

~~~kotlin
class Person(val name: String)

fun main() {
    val person = Person("Yurim")
    with(person) {
        println("Hello, I'm $name") // OK! 내부처럼 작동
    }
}
~~~
- `with(obj) { name }` : obj가 리시버
- `obj.apply { name }` : obj가 리시버
  - apply: 객체 수정/초기화, 자기 자신 그대로 리턴 - 체이닝 가능
- `fun String.foo()` : String이 리시버 타입

  | 함수      | 블록 안에서 객체 접근 방식 | 리턴값      | 주로 쓰는 목적              |
  | ------- | --------------- | -------- | --------------------- |
  | `apply` | `this`          | 객체 자기 자신 | 객체 초기화, 구성 설정         |
  | `also`  | `it`            | 객체 자기 자신 | 로그, 부가 작업, 디버깅용       |
  | `let`   | `it`            | 마지막 식 결과 | null-safe 처리, 체이닝, 가공 |

#### 레이블
- 리시버(this)가 여러 개인 경우, 명확히 어떤 this를 말하는 건지 정확히 지정하기 위한 장치
| 문법               | 설명                     |
| ---------------- | ---------------------- |
| `this`           | 가장 가까운 리시버             |
| `this@LabelName` | 특정한 바깥 리시버를 명시함        |
| `Label@`         | 블록에 레이블 붙이기 (optional) |
