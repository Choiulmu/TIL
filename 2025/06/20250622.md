# 코틀린 기본문법

### 클래스 상속
- :(기호) 사용
- open 키워드
~~~kotlin
open class Animal {
    fun breathe() = println("Breathing")
}

class Dog: Animal() {
    fun bark() = println("Bark!")
}
~~~


### 인터페이스 구현
- interface
- override 키워드로 메서드 구현
~~~kotlin
interface Walkable {
    fun walk()
}

class Human : Walkable {
    override fun walk() {
        prinln("Walking on two legs")
    }

}
~~~


### Smart casts
- is 체크 이후 자동으로 타입 변환
- 변수의 값이 변하지 않는 경우에만(val 변수)
- when + return문 조합으로 많이 사용
~~~kotlin
fun getType(input: Any): String {
    return when (input) {
        is String -> "It's a string"
        is Int -> "It's an integer"
        else -> "Unknown type"
}
~~~
~~~kotlin
val result = when (input) {
    is String -> "String"
    is Int -> "Integer"
    else -> "Other"
}
~~~

### Sealed class
- 상속 가능한 타입 제한
- when으로 분기할 때 모든 경우를 컴파일러가 체크
- interface를 상속받을 때는 () 생략
~~~ kotlin
sealed class Result

calss Success(val data: String) : Result()
class Error(val message: String) : Result()
object Loadding : Result()

fun handleResult(result: Result) {
    when(result) {
        is Success -> println("Success: ${result.data}")
        is Error -> println("Error: ${result.message}")
        Loading -> println("Loading...")
    }
}
~~~

### 형변환
1) as: 명시적 형변환
- 타입다르면 ClassCastException
~~~kotlin
val obj: Any = "Hello"
val str = obj as String
println(str.length)
~~~
2) as?: 안전한 형변환
~~~kotlin
val obj: Any = "Hello"
val str = obj as? String
println(str?.length)
~~~
3) is + SmartCast

### Extension Function
- 기존 클래스에 함수를 추가
- 원래 그 클래스 안에 있지 않아도 사용 가능
~~~kotlin
fun String.sayHello(): String {
    return "Hello, $this!"
    
val name = "urim"
println(name.sayHello())
}
~~~
